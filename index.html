01 Research · Oct 2026 – Present

      
ATMC: verified-failure memory for coding agents

      
A coding assistant that learns a team's hidden conventions from its own failures. A sandbox checker says exactly what was expected, that evidence is stored as a note, and a passing retry becomes a worked example. No weight updates; it runs on a laptop with a local model.

      
    
        
  • Wrote a 110-question hidden-convention benchmark with a held-out set and rule-change streams.
    • 
        
  • A bounded rule memory with execution-based staleness detection recovered +23 to +26 points after conventions changed, storing 62–78% fewer notes.
    • 
        
  • Pre-registered experiments; ideas that did not work are reported in the README.
    •

03 AI agent · Oct 2026 · Hacktoberfest

      
Boot Upgrade Agent

      
Upgrades Spring Boot 2.7 apps to Spring Boot 3 with a local open-weight model, then checks that the upgrade did not silently change who can access what.

      
    
        
  • A test-integrity guard stops the agent from editing tests or build files; the upgraded app must run the same tests as the original.
    • 
        
  • Replays requests as anonymous, user and admin against the old and new build to flag changed access.
    • 
        
  • Upgraded both sample apps in 3 of 3 runs. It did not pass on a held-out app, and the benchmark says so.
    •

05 Data / ML · Oct 2026

      
TaskClean: task-aware data quality

      
Measures how much each data-quality problem actually hurts an ML task, and only repairs automatically what it can show is safe.

      
    
        
  • Injects one error type at a time into UCI Adult and measures F1 loss on an untouched clean test set.
    • 
        
  • Repairs apply automatically only with zero observed harm and precision of at least 0.95; the rest is flagged for review.
    • 
        
  • Also a usable tool: upload a CSV, get a cleaned dataset, a repair log and a readiness report.
